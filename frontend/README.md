# COD Guard frontend

Shop web app and buyer confirmation page. React 19 + TypeScript on Vite.

| Concern      | Library                                                                                                                                                    |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Components   | [shadcn/ui](https://ui.shadcn.com) (`src/components/ui/`) and [ReUI](https://reui.io) (`src/components/reui/`, e.g. the data grid)                         |
| Page blocks  | ReUI blocks adapted to COD Guard (`src/components/blocks/`): `app-shell-1` is the shop layout, `auth-4` the login page, `data-grid-base-1` the order table |
| Styling      | Tailwind CSS v4, theme tokens in `src/index.css`                                                                                                           |
| Routing      | TanStack Router, file-based (`src/routes/`, generates `src/routeTree.gen.ts`)                                                                              |
| Server state | TanStack Query, with query options generated by Hey API                                                                                                    |
| API client   | [Hey API](https://heyapi.dev) generated from `api/openapi.yaml` into `src/api/gen/`                                                                        |
| Client state | Zustand (`src/stores/`): auth token and theme, both kept in `localStorage`                                                                                 |
| Tests        | Vitest + Testing Library                                                                                                                                   |

## Commands

Run from `frontend/`. Needs Node.js 20+ and pnpm (`corepack enable` picks up the version pinned in `package.json`).

| Task                      | Command                                        |
| ------------------------- | ---------------------------------------------- |
| Install                   | `pnpm install`                                 |
| Dev server                | `pnpm dev` (http://localhost:5173)             |
| Mock API                  | `pnpm mock` (Prism on :4010)                   |
| Regenerate the API client | `pnpm generate:api`                            |
| Lint                      | `pnpm lint` (oxlint)                           |
| Format                    | `pnpm format` / `pnpm format:check` (Prettier) |
| Type check                | `pnpm typecheck`                               |
| Tests                     | `pnpm test`                                    |
| Production build          | `pnpm build` (output in `dist/`)               |

## Talking to the API

The app calls `/api/...` on its own origin. In development Vite proxies `/api` to the Prism mock
on port 4010; set `API_PROXY_TARGET=http://127.0.0.1:8080` to use the local backend instead.

```bash
pnpm mock                                        # Prism on :4010, in its own terminal
cp .env.example .env.local                       # sets a dev bearer token for the mock
pnpm dev
```

The client is generated, never edited by hand. After the backend changes the contract and
re-exports `api/openapi.yaml`, run `pnpm generate:api` and commit `src/api/gen/`. CI fails when
the generated client is out of date.

```tsx
import { useQuery } from '@tanstack/react-query'
import { listOrdersOptions } from '@/api/gen/@tanstack/react-query.gen'

const { data, error } = useQuery(listOrdersOptions({ query: { tier: ['high'], limit: 50 } }))
```

Base URL and auth are set in `src/api/client-config.ts`: the bearer token comes from the Zustand
auth store. A 401 from the API signs the user out. Errors are thrown as the parsed `ProblemDetail`
body; `src/components/query-error.tsx` shows them.

## Signing in

`/login` (ReUI `auth-4`) signs in with email and password. Every shop route sits under the
`_shop` layout, which sends signed-out users to `/login?redirect=…` and back afterwards.

`signIn` in `src/lib/auth.ts` calls `POST /api/v1/auth/login` and stores the returned token.
Against the backend, use the account from the repo's `.env` (`admin@gmail.com` / `admin12345` in
`.env.example`); the Prism mock accepts any credentials.

## Adding components

- shadcn: `pnpm dlx shadcn@latest add <name>`.
- ReUI: `components.json` points the `@reui` registry at a local mirror on port 4000. Start it
  with `reui serve`, then `REGISTRY_URL=http://localhost:4000/r/styles/radix-nova pnpm dlx shadcn@latest add @reui/<name> --yes`.
  Without the mirror, change the `@reui` entry to `https://reui.io/r/{style}/{name}.json`.
- Files under `src/components/ui/` and `src/components/reui/` come from the registries. Prefer
  reinstalling over editing them; ReUI files are skipped by oxlint and Prettier.
- Blocks under `src/components/blocks/` are installed once and then adapted (real data, routes,
  Vietnamese copy), so they are linted and formatted like our own code. Do not reinstall them over
  the adapted files.
